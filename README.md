# RUNLOG 個人賽事日誌

> 一個免費、免註冊的跑步網頁：記錄馬拉松與路跑成績、看配速與進步、查詢未來賽事、設定目標並倒數。
> 資料只存在你自己的手機或電腦，不上傳、不收集。

**網址：** https://tommylee0317-prog.github.io/R/

---

## 一、這是什麼？

RUNLOG 是專為跑者設計的「個人賽事日誌」網頁。每跑完一場比賽，把成績記下來，它會幫你整理出：

- 各距離的個人最佳（PB）與累積里程
- 配速趨勢、年度里程圖表
- 想參加的賽事倒數天數
- 年度里程目標的達成進度

可以在手機、平板、電腦使用，也能像 App 一樣加到手機主畫面。

## 二、主要功能

| 功能 | 說明 |
|---|---|
| **總覽** | 一眼看到個人最佳、累計場次與里程、近期賽事，以及「目標與倒數」 |
| **賽事紀錄** | 新增、編輯、刪除每一場成績；可搜尋、依距離篩選；支援匯入／匯出 Excel |
| **成績分析** | 配速趨勢圖、全馬／半馬分布、年度完賽里程 |
| **配速計算器** | 輸入距離與完賽時間，算出每公里配速、時速，以及相同配速跑 5K／10K／半馬／全馬的預估時間 |
| **可參加賽事** | 整合「跑者廣場全國賽會」與「中華民國路跑協會」的賽事行事曆，可依年月查詢、點名稱前往報名頁，按 ☆ 收藏 |
| **人員管理** | 一個瀏覽器可建立多位跑者（例如家人、跑友），各自獨立記錄；可改名、刪除、備份與還原 |
| **外觀設定（Aa）** | 自訂字型、字體大小、主題色、文字顏色；另有深色／淺色模式 |
| **手機／電腦切換** | 右下角圓形按鈕可切換顯示模式；手機版頂端有「上一頁」「回首頁」按鈕 |

支援的距離：**全馬、半馬、10K、5K、超馬、其他距離**（超馬與其他距離需自行填寫實際公里數）。

## 三、開始使用（操作步驟）

### 1. 新增第一場賽事
1. 點右上角 **「＋ 新增賽事」**（或首頁的「記錄我的里程碑」）。
2. 填寫：賽事名稱、完賽日期、賽事距離、完賽時間（時：分：秒）。地點與筆記可不填。
3. 按 **「儲存紀錄」**。總覽會立刻更新你的個人最佳與統計。

> 第一次打開時，網頁內有一組「臺北馬拉松」的範例（全馬 3:35:00、半馬 1:40:00），讓你看看畫面。可以直接修改或刪除，換成自己的成績。

### 2. 查看與整理紀錄
- 左側選單 **「賽事紀錄」**：用搜尋框找賽事或地點；上方按鈕可只看全馬、半馬或其他距離。
- 每筆右側有 ✎ 編輯、× 刪除。
- **匯入 Excel**：從舊表格一次匯入，欄位需包含「賽事名稱、日期、距離組別、完賽時間」（地點、筆記可選），重複的會自動略過。
- **匯出 Excel**：把紀錄存成 `RUN.xlsx`，方便備份或自己分析。

### 3. 看成績分析
左側選單 **「成績分析」**：可選年度，查看配速趨勢（越低越快）、全馬與半馬比例、每年累積里程。

### 4. 用配速計算器規劃比賽
左側選單 **「配速計算器」**：選常用距離（5K／10K／半馬／全馬）或自行輸入公里數，填入目標完賽時間，按 **「計算我的配速」**，馬上得到每公里配速與各距離的預估時間。

### 5. 找比賽、收藏、倒數
1. 左側選單 **「可參加賽事」**，選擇年份與月份。
2. 點賽事名稱會開新分頁，前往主辦單位的活動／報名頁。
3. 按該列右邊的 **☆** 收藏。
4. 回到 **「總覽」**，最下方的「目標賽事倒數」會顯示還有幾天；按 ✕ 可取消收藏。

賽事資料約每 6 小時更新一次。活動與報名資訊可能異動，**請以主辦單位公告為準**。

### 6. 設定年度目標
在 **「總覽」→「目標與倒數」** 輸入今年想完成的公里數，按「儲存目標」，進度條會依你今年已記錄的賽事里程自動計算。（目前只計算賽事里程，不含平常訓練。）

### 7. 多位跑者共用一個瀏覽器
1. 左側選單 **「人員管理」**，輸入姓名，按「新增人員」。
2. 在人員清單可「切換」「改名」「刪除」。刪除會連同該人員的所有賽事紀錄，**無法復原**。
3. 畫面左下角的下拉選單也能快速切換人員；右邊的表單可直接替選定的人員新增賽事。

### 8. 調整外觀
- 頂端的 **Aa**：選字型、調整字體大小（80%–140%）、挑主題色、改文字顏色，「全部還原」可回到預設。
- 旁邊的 ◐ 按鈕：切換深色／淺色模式。

## 四、資料存在哪裡？會不會外流？

- 所有資料（賽事、人員、目標、收藏）都存在**你自己這台裝置的瀏覽器裡**，不會上傳到任何伺服器，作者也看不到。
- 不同裝置之間**不會同步**；換手機、換電腦、換瀏覽器，資料不會跟著過去。
- 如果清除瀏覽器資料、使用無痕模式，或長時間不使用（部分瀏覽器會自動清理），資料可能消失。

### 備份與還原（強烈建議）
**人員管理** 頁最下方的「備份與還原」：
- **匯出完整備份（JSON）**：下載一個備份檔（所有人員、紀錄、目標、收藏）。
- **匯入備份**：選擇備份檔還原。**會取代目前瀏覽器裡的所有資料**。

建議每個月、或更換手機前備份一次。要把資料搬到新手機：在舊手機匯出備份檔，傳到新手機（AirDrop、LINE、雲端硬碟皆可），再在新手機匯入。

## 五、在 iPhone 用 Safari 加到主畫面（變成 App）

加到主畫面後，網頁會像 App 一樣有自己的圖示，開啟時沒有網址列、全螢幕顯示。

**步驟（iOS／iPadOS，請使用 Safari）：**
1. 用 **Safari** 開啟 https://tommylee0317-prog.github.io/R/ 。
2. 點螢幕下方（iPad 在右上方）的 **分享按鈕**（方形加向上箭頭 ⬆︎）。
3. 在選單往下滑，點 **「加入主畫面」**。
4. 名稱預設為「RUNLOG」，可自行修改。若看到 **「作為網頁 App 開啟」** 的開關，請保持開啟。
5. 按右上角 **「加入」**。
6. 回到主畫面，就能看到 RUNLOG 圖示，點它即可開啟。

**重要提醒（iPhone）：**
- **主畫面 App 與 Safari 的資料是分開的。** 先在 Safari 記的資料，不會出現在主畫面 App 裡。建議一開始就用主畫面 App 記錄；若已在 Safari 記了資料，請在 Safari 的「人員管理」匯出備份，再到主畫面 App 匯入。
- 目前的 iPhone 上，只用 Safari 瀏覽（沒加到主畫面）的網站，長時間沒開啟，資料可能被系統自動清除；加到主畫面的 App 比較不會，但仍請定期備份。
- 如果「加入主畫面」找不到：請確認用的是 Safari（不是 App 內建瀏覽器，例如在 LINE、Facebook 裡直接開的網頁），並更新到較新的 iOS。

### Android（Chrome）
1. 用 Chrome 開啟網址。
2. 點右上角 **⋮**，選 **「安裝應用程式」**（或「加到主畫面」）。
3. 確認後，主畫面會出現圖示。

### 電腦（Chrome／Edge）
網址列右側如果出現安裝圖示 ⊕，或選單中有「安裝 RUNLOG」，點它即可變成桌面應用程式。

## 六、常見問題

**Q：要註冊或登入嗎？**　不用，打開就能用。

**Q：我的成績別人看得到嗎？**　看不到。資料只在你的裝置上。但同一個瀏覽器、同一個使用者設定檔裡的人，看到的是同一份資料；需要分開請用「人員管理」，或各自用自己的瀏覽器。

**Q：資料不見了怎麼辦？**　如果有備份，到「人員管理」匯入即可；沒有備份就無法復原，請養成定期備份的習慣。

**Q：可參加賽事的資料不是最新的？**　賽事清單約每 6 小時更新一次，且來源網站本身也可能延遲；請以主辦單位官網為準。

**Q：手機版面怪怪的？**　按右下角圓形按鈕，選「手機版」或「電腦版」切換，也可以強制重新整理頁面（Windows：Ctrl+F5；Mac：⌘+Shift+R）。

**Q：可以記錄平常的訓練嗎？**　目前主要記錄「賽事成績」，還不含日常訓練。
